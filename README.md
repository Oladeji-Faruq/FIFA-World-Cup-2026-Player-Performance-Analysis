**⚽FIFA World Cup 2026 Player Performance Analysis**

**📊Project Overview**

This project is designed to explore player statistics, performance metrics, team representation overall contribution in the just concluded 2026 FIFA World Cup.

The project demonstrates the end-to-end process of taking a raw football dataset, cleaning and preparing the data, performing analysis using Excel, and presenting the findings through an interactive dashboard.
The goal was to transform a large and complex dataset into a format that makes it easier to identify player performance patterns, compare players, and explore football statistics from different perspectives.

## 🎯 Project Objectives

The analysis was designed to answer questions such as:
* Which players have the strongest attacking performances?
* How are players distributed across different positions?
* Which teams and countries have the largest player representation?
* How does player performance vary across different metrics?
* Which players stand out based on goals, assists, shots, and other performance indicators?
* What patterns can be identified from player participation and performance statistics?

**🗂️ Dataset**
The original dataset contains **1,248 football player records** and **72 variables** covering player information, participation, attacking statistics, disciplinary statistics, defensive statistics, and goalkeeper statistics.

## 🧹 Data Preparation & Cleaning

Before analysis, the raw dataset was reviewed and transformed into a cleaner analysis-ready dataset.

The workflow included:

1. Reviewing the original dataset structure.
2. Identifying missing and incomplete values.
3. Cleaning and organizing the dataset.
4. Preparing fields for analysis.
5. Using the cleaned dataset as the foundation for analysis and dashboard development.
